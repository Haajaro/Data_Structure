Inpatient

The Inpatient class inherits from the Patient class. It calculates the total bill using the consultation fee, room charge, and number of days.

Formula: Total Bill = (Room Charge × Number of Days) + Consult Fee

Output

=== INPATIENT ===
Name: Amina
Consult Fee: $50.0
Room Charge: $100.0
Number of Days: 3
Total Bill: $350.0

Explanation: The room charge is $100 per day for 3 days, totaling $300. Adding the $50 consultation fee gives a total bill of $350.

Methods Used

CalculateBill() – Calculates the total hospital bill.

Display() – Displays the patient's information and total bill.

OOP Concept

Inheritance: Both Outpatient and Inpatient inherit the patient's name and consultation fee from the Patient superclass.
