# Outpatient Class

## Description
The Outpatient class represents patients who visit the hospital for consultation without staying overnight.

## Features
- Stores outpatient information.
- Calculates consultation fees.
- Calculates laboratory charges.
- Displays patient information and the total bill.

## OOP Concepts
- Inheritance
- Method Overriding
- Constructors

## Sample Output
```text
=== OUTPATIENT ===
Name: Mohamed
Consult Fee: $50.0
Lab Charge: $30.0
Total Bill: $80.0
```

## Conclusion
The Outpatient class calculates and displays the total bill for outpatient services.
